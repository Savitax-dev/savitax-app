2. Danh sách công ty

Danh sách dùng chung cho cả 3 phân hệ. Ô Công ty đang làm ở đầu menu trái chọn công ty cho mọi màn hình.

Thêm công ty

  • Từng công ty: bấm ＋ Thêm công ty, gõ MST rồi bấm 🔍 để tự điền tên, địa chỉ (cần mạng), chọn kỳ khai Quý / Tháng, đánh dấu nếu là hộ kinh doanh.
  • Cả danh sách: mở Mau-danh-sach-cong-ty.xlsx, điền mỗi công ty một dòng (giữ nguyên hàng tiêu đề), rồi bấm 📥 Nhập từ Excel. Nút 📤 Xuất Excel lưu lại danh sách đang có.

Trỏ thư mục công ty

Soát xét báo cáo và Rủi ro thuế đọc hồ sơ ngay trong thư mục của công ty trên ổ chung. Bấm Trỏ thư mục ở dòng công ty → chọn thư mục GỐC của công ty (thư mục có 2. HỒ SƠ KẾ TOÁN) → Chrome hỏi quyền xem file → bấm Cho phép.

  • Chương trình chỉ đọc: không ghi, không đổi tên, không xoá file nào trong thư mục.
  • Lần mở sau, Chrome có thể hỏi lại quyền một lần → bấm Cho phép.
  • Năm cũ nằm ở thư mục khác thì trỏ thêm ở nút ＋ Năm cũ trong phân hệ Soát xét.

5. Hồ sơ chứng từ

Lập bộ chứng từ từ hóa đơn — không cần trỏ thư mục. Công ty ở Danh sách công ty tự là khách hàng; chọn ở menu trái là chọn khách hàng đang làm.

  1. Lập hồ sơ từ hóa đơn: kéo thả file hóa đơn XML (tốt nhất), PDF có lớp chữ hoặc ZIP tải từ cổng tra cứu. Tải nhiều file một lúc được. Không có file thì nhập tay.
  2. Chương trình tự nhận bán ra / mua vào theo MST công ty đang làm, đoán nghiệp vụ (hàng hóa, dịch vụ, xây dựng…) kèm lý do — kiểm lại và sửa nếu sai.
  3. Chương trình dựng sẵn bộ chứng từ: hợp đồng, đơn hàng, biên bản giao nhận, phiếu nhập / xuất… điền sẵn bên mua, bên bán, ngày, số.
  4. Xem checklist đủ / thiếu và các cảnh báo (thanh toán từ 5 triệu, ngày giao khác ngày hóa đơn, lệch tổng tiền, MST sai…).
  5. Xuất Word, PDF, Excel, phiếu kiểm tra hồ sơ, hoặc ZIP nhiều hồ sơ.
  6. Hồ sơ lưu vào Sổ hồ sơ để tìm lại. Mẫu chứng từ sửa được ở tab Mẫu chứng từ (soạn trực tiếp hoặc nhập mẫu Word).

Chi tiết từng bước và chỗ lưu file theo cây SVT.MB09 xem tab 🧭 Hướng dẫn trong phân hệ.

Tổng quan Hồ sơ chứng từ (hóa đơn minh họa có sẵn trong chương trình).

6. Cài đặt, sao lưu, chuyển máy

  • Thương hiệu đơn vị: chọn logo (PNG / JPG), tên, MST, địa chỉ → Lưu thương hiệu. Logo hiện ở góc trên menu và trên phiếu kiểm tra hồ sơ chứng từ. Để trống là Savitax.
  • Ngày nghỉ lễ: có sẵn ngày lễ, Tết, nghỉ bù 2026–2027. Mỗi đầu năm thêm ngày nghỉ năm mới (ngày âm lịch, nghỉ bù đổi theo năm) — dùng để tính hạn nộp và lùi ngày chứng từ.
  • Sao lưu (JSON): lưu danh sách công ty, cài đặt và toàn bộ hồ sơ chứng từ ra một file. Nên sao lưu mỗi tuần và trước khi dọn trình duyệt.
  • Khôi phục: chọn file sao lưu → thay dữ liệu đang có bằng dữ liệu trong file.
Cài đặt: thương hiệu, ngày nghỉ lễ, sao lưu / khôi phục.

Chuyển sang máy khác

  1. Máy cũ: Cài đặt → Sao lưu (JSON).
  2. Máy mới: chép thư mục chương trình, mở bằng Chrome / Edge → Cài đặt → Khôi phục → chọn file sao lưu.
  3. Trỏ lại thư mục từng công ty (quyền đọc thư mục không chuyển được giữa các máy).

Cập nhật bản mới

Sao lưu trước, rồi thay file HTML cũ bằng file mới (mở trên cùng máy, cùng trình duyệt). Dữ liệu vẫn còn vì nằm trong trình duyệt, không nằm trong file HTML.

Xoá dữ liệu duyệt web (cookie và dữ liệu trang web) là mất dữ liệu của chương trình. Chế độ ẩn danh không giữ lại gì sau khi đóng cửa sổ. Luôn giữ một file sao lưu mới nhất.
