5Điều kiện & giới hạn

  • Trình duyệt: Chrome hoặc Edge trên máy tính (cần trỏ thư mục). Firefox, Safari, điện thoại: chỉ xem được Hồ sơ chứng từ, không soát được thư mục.
  • Mỗi máy một kho riêng: hai người hai máy không thấy dữ liệu của nhau. Muốn chuyển máy → Sao lưu JSON → Khôi phục.
  • Xoá dữ liệu duyệt web (cookie & dữ liệu trang) là mất kho → nhắc sao lưu định kỳ, app hiện ngày sao lưu gần nhất.
  • Giữ file ở một chỗ cố định: mọi file mở từ ổ đĩa dùng chung một vùng lưu, nên kho đặt tên riêng savitax-hoso để không lẫn với file HTML khác.
  • Mở lần đầu mỗi phiên, Chrome hỏi lại quyền đọc thư mục đã trỏ — bấm "Cho phép" một lần.
  • Bản quyền: dòng "Bản quyền © Savitax" nằm cứng trong file; khách đổi logo / tên / địa chỉ ở Cài đặt.
